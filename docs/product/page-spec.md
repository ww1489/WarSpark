# WarSpark 页面规格说明

## 1. 文档目的

本文档定义 WarSpark MVP 页面级产品规格，供前端拆页面、后端确认接口字段、QA 提炼验收用例使用。

页面规格基于：

- `docs/product/warspark-prd.md`
- `docs/product/mvp-scope.md`
- `docs/product/user-flows.md`

本文档只定义产品行为和信息结构，不定义最终视觉风格。

## 2. 页面清单

| 页面 | MVP 状态 | 关联流程 |
| --- | --- | --- |
| 作战台 / 首页 | 必做 | F1, F2 |
| 找阵页 | 必做 | F1 |
| 找阵结果页 | 必做 | F1, F2, F3, F6, F7, F8 |
| 阵型库列表页 | 必做 | F5 |
| 阵型详情页 | 必做 | F3, F5, F8 |
| 战争情报页 | 占位 / V1 | F2 |
| 复盘页 | 占位 / V2 | F9 |

## 3. 通用页面规则

### 3.1 通用状态

所有核心页面需要考虑：

- 加载状态：数据请求中。
- 空状态：没有可展示数据。
- 错误状态：请求失败或数据不可用。
- 低置信度状态：结果可参考但不应被当作精确匹配。
- 链接失效状态：外部链接不可用。

### 3.2 通用动作

常见用户动作：

- 上传截图。
- 重新上传。
- 打开视频。
- 打开 OpenLayout。
- 复制 OpenLayout。
- 进入阵型详情。
- 返回上一级。
- 重置筛选。

### 3.3 通用文案原则

- 低置信度结果必须明确说明。
- 无结果不能伪装成匹配结果。
- 失效链接必须禁用主要操作。
- 不使用“推荐打法”“最佳打法”等强承诺文案。
- 使用“相关视频”“相似阵型”“防守回放”“视频参考”等保守表达。

## 4. P1 作战台 / 首页

### 4.1 页面目标

作战台是 WarSpark 的默认入口。MVP 阶段优先承接两个动作：

- 上传阵型截图。
- 输入部落 tag / 玩家 tag 的预留入口。

### 4.2 核心模块

| 模块 | 字段 / 内容 | 动作 |
| --- | --- | --- |
| 截图找阵入口 | 标题、简短说明、上传提示 | 上传截图，进入找阵页 |
| 战争情报入口 | 部落 tag / 玩家 tag 输入框、V1 提示 | 输入 tag，进入战争情报占位或 V1 页面 |
| 最近找阵记录 | 截图缩略图、TH、状态、时间 | 打开结果页 |
| 热门入口 | 热门 TH、热门阵型、热门视频 | 进入阵型库筛选结果 |

### 4.3 MVP 字段

- `recent_search_id`
- `thumbnail_url`
- `detected_th`
- `search_status`
- `created_at`
- `tag_input`

### 4.4 页面状态

加载状态：

- 展示首页骨架。
- 最近记录加载中。

空状态：

- 没有最近找阵记录时，显示上传截图入口。

错误状态：

- 最近记录加载失败时，不影响上传入口。

### 4.5 MVP 不做

- 不做用户登录后的个人首页。
- 不做完整战争看板。
- 不做个性化推荐流。

## 5. P2 找阵页

### 5.1 页面目标

帮助用户上传截图，并清楚理解上传要求和处理状态。

### 5.2 核心模块

| 模块 | 字段 / 内容 | 动作 |
| --- | --- | --- |
| 上传区域 | 文件选择、拖拽提示、支持格式 | 选择图片，提交 |
| 上传说明 | 建议截图清晰、完整阵型、减少 UI 遮挡 | 无 |
| 目标上下文 | 敌方序号、玩家名、TH，占位可为空 | 返回目标页 |
| 处理状态 | created、processing、failed | 等待、重新上传 |

### 5.3 MVP 字段

- `image_file`
- `source_context`
- `target_player_name`
- `target_position`
- `expected_th`
- `upload_status`
- `error_message`

### 5.4 页面状态

加载状态：

- 文件上传中。
- 找阵任务处理中。

空状态：

- 未选择文件时显示上传说明。

错误状态：

- 文件格式不支持。
- 文件过大。
- 上传失败。
- 处理失败。

### 5.5 用户动作

- 选择图片。
- 提交上传。
- 取消上传。
- 重新上传。
- 返回首页或目标页。

### 5.6 MVP 不做

- 不做复杂图片编辑器。
- 不做手动裁剪。
- 不做批量上传。

## 6. P3 找阵结果页

### 6.1 页面目标

展示截图识别结果、相似阵型、相关攻击视频、防守回放和可复制链接，让用户快速获得可学习参考。

### 6.2 核心模块

| 模块 | 字段 / 内容 | 动作 |
| --- | --- | --- |
| 目标上下文 | 敌方序号、玩家名、TH、当前被打情况 | 返回战争目标 |
| 检测信息 | 检测 TH、截图质量、识别状态、建筑数量 | 重新上传 |
| 匹配摘要 | 匹配等级、候选数量、低置信度提示 | 查看说明 |
| 相似阵型 | 阵型图片、TH、类型、风格、来源、状态 | 进入阵型详情 |
| 进攻视频 | 标题、频道、星数、摧毁率、时间戳、标签 | 打开 YouTube |
| 防守回放 | 标题、频道、攻击结果、时间戳 | 打开 YouTube |
| 复制链接 | OpenLayout、官方复制链接、链接状态 | 打开、复制 |
| 空状态 | 无结果说明、重新上传、同 TH 热门视频 | 重新上传、查看热门 |

### 6.3 MVP 字段

- `search_id`
- `search_status`
- `detected_th`
- `screenshot_quality`
- `buildings_detected`
- `match_level`
- `candidate_count`
- `layout_id`
- `layout_image_url`
- `layout_status`
- `open_layout_url`
- `link_status`
- `video_id`
- `youtube_video_id`
- `timestamp_seconds`
- `video_title`
- `channel_name`
- `stars`
- `destruction_percent`
- `video_group`

### 6.4 页面状态

加载状态：

- 结果生成中。
- 视频和阵型候选加载中。

低置信度状态：

- 页面顶部显示低置信度提示。
- 相似阵型卡片显示匹配等级。
- 相关视频显示“相似参考”或“同 TH 参考”。

无结果状态：

- 展示识别到的 TH 或截图质量说明。
- 展示重新上传入口。
- 展示同 TH 热门视频入口。
- 展示手动提交或反馈入口。

链接失效状态：

- 禁用复制 / 打开动作。
- 显示链接失效标记。
- 如果有备用链接，展示备用链接。

错误状态：

- 找阵任务失败。
- 结果读取失败。
- 图片不可访问。

### 6.5 用户动作

- 打开视频时间戳。
- 复制 OpenLayout。
- 打开 OpenLayout。
- 进入阵型详情。
- 重新上传。
- 返回首页或目标页。

### 6.6 MVP 不做

- 不做自动打法总结。
- 不做配兵链接提取。
- 不做 AI 推荐打法。
- 不做一键收藏。

## 7. P4 阵型库列表页

### 7.1 页面目标

展示找阵过程中沉淀下来的阵型资产，让用户浏览、筛选和进入详情。

### 7.2 核心模块

| 模块 | 字段 / 内容 | 动作 |
| --- | --- | --- |
| 筛选栏 | TH、类型、风格、来源、审核状态 | 筛选、重置 |
| 阵型卡片 | 图片、TH、类型、风格、来源、质量状态、链接状态 | 进入详情 |
| 结果数量 | 当前筛选数量 | 无 |
| 空状态 | 无匹配阵型说明 | 重置筛选 |

### 7.3 MVP 字段

- `layout_id`
- `layout_image_url`
- `th_level`
- `layout_type`
- `style_tags`
- `source_type`
- `review_status`
- `quality_status`
- `link_status`
- `updated_at`

### 7.4 页面状态

加载状态：

- 列表骨架和筛选栏禁用。

空状态：

- 当前筛选无结果。
- 阵型库暂无内容。

错误状态：

- 列表加载失败。
- 图片加载失败。

### 7.5 用户动作

- 选择筛选条件。
- 重置筛选。
- 打开阵型详情。
- 打开找阵页。

### 7.6 MVP 不做

- 不做用户投稿。
- 不做收藏、点赞、评论。
- 不做复杂排序算法。
- 不做付费阵型。

## 8. P5 阵型详情页

### 8.1 页面目标

提供单个阵型的完整参考信息：图片、OpenLayout、来源、质量状态、关联视频、防守记录和相似阵型。

### 8.2 核心模块

| 模块 | 字段 / 内容 | 动作 |
| --- | --- | --- |
| 阵型图片 | 主图、图片状态 | 放大查看 |
| 基础信息 | TH、类型、风格、来源、审核状态、质量状态 | 无 |
| 复制链接 | OpenLayout、链接状态、来源 | 打开、复制 |
| 关联视频 | 标题、频道、时间戳、星数、摧毁率 | 打开视频 |
| 防守记录 | 攻击结果、星数、摧毁率、备注 | 打开视频 |
| 相似阵型 | 图片、TH、类型、匹配说明 | 打开详情 |

### 8.3 MVP 字段

- `layout_id`
- `layout_image_url`
- `th_level`
- `layout_type`
- `style_tags`
- `source_type`
- `source_url`
- `review_status`
- `quality_status`
- `open_layout_url`
- `link_status`
- `related_videos`
- `defense_replays`
- `similar_layouts`

### 8.4 页面状态

加载状态：

- 详情骨架。

空状态：

- 无关联视频。
- 无防守记录。
- 无可用 OpenLayout。

链接失效状态：

- OpenLayout 区域展示失效状态。
- 禁用复制和打开。

低置信度状态：

- 页面顶部展示低置信度说明。
- 来源和质量状态显式展示。

错误状态：

- 阵型不存在。
- 阵型被隐藏。
- 图片不可用。

### 8.5 用户动作

- 打开或复制 OpenLayout。
- 打开 YouTube 时间戳。
- 进入相似阵型详情。
- 返回阵型库或找阵结果页。

### 8.6 MVP 不做

- 不做编辑阵型。
- 不做用户评论。
- 不做付费解锁。
- 不做复杂防守评分。

## 9. P6 战争情报页

### 9.1 页面目标

MVP 阶段只做入口和结构预留，V1 完整实现战争数据接入。

### 9.2 MVP 模块

| 模块 | 字段 / 内容 | 动作 |
| --- | --- | --- |
| Tag 输入 | 部落 tag、玩家 tag | 查询 |
| 占位说明 | 当前战争数据将在 V1 接入 | 返回首页 |
| 找阵入口 | 上传截图，不依赖战争数据 | 进入找阵页 |

### 9.3 V1 模块

| 模块 | 字段 / 内容 | 动作 |
| --- | --- | --- |
| 战争概览 | 双方部落、星数、摧毁率、状态、剩余时间 | 刷新 |
| TH 分布 | 我方 TH、敌方 TH | 无 |
| 敌方列表 | 序号、玩家、TH、被打情况 | 进入目标情报 |
| 我方列表 | 玩家、TH、攻击次数、已打目标 | 无 |
| 风险提示 | 未出手成员、低星记录、高价值目标 | 查看目标 |

### 9.4 MVP 不做

- 不做完整 War Report。
- 不做历史战争查询。
- 不做推送提醒。
- 不做多账号同步。

## 10. P7 复盘页

### 10.1 页面目标

MVP 阶段只预留入口和数据结构，V2 完整实现。

### 10.2 V2 模块

| 模块 | 字段 / 内容 | 动作 |
| --- | --- | --- |
| 战争结果 | 胜负、星数、摧毁率、攻击效率 | 无 |
| 攻击记录 | 谁打谁、星数、摧毁率 | 关联阵型 |
| 防守记录 | 哪个阵被打、结果、视频或备注 | 关联视频 |
| 阵型表现 | 高防守阵型、低防守阵型 | 进入详情 |
| 资料沉淀 | 标记关键阵型、关键视频 | 保存 |

### 10.3 MVP 不做

- 不做完整复盘页。
- 不做复杂统计图表。
- 不做自动失败原因分析。

## 11. 页面间跳转

| 来源 | 目标 | 动作 |
| --- | --- | --- |
| 作战台 | 找阵页 | 上传截图 |
| 找阵页 | 找阵结果页 | 上传处理完成 |
| 找阵结果页 | 阵型详情页 | 点击相似阵型 |
| 找阵结果页 | 找阵页 | 重新上传 |

| 阵型详情页 | YouTube | 打开视频时间戳 |
| 阵型详情页 | OpenLayout | 打开复制链接 |
| 战争情报页 | 找阵页 | 为目标上传截图 |

## 12. 页面验收标准

页面规格视为完成时，需要满足：

- 覆盖作战台、找阵页、找阵结果页、阵型库列表、阵型详情、战争情报页。
- 每个 MVP 页面都有核心模块、字段、状态和用户动作。
- 明确加载、空、错误、低置信度、链接失效状态。
- 明确哪些页面在 MVP 只做占位。
- 不包含登录、收藏、付费、AI 打法推荐等非 MVP 能力。
